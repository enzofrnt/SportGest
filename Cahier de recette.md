# Cahier de recette

## BackOffice

- [ ] Un Administrateur peut réaliser le CRUD sur tout les éléments
- [ ] Un Responsable peut réaliser le CRUD sur tous les éléments sauf les Responsables
- [ ] Un Caoch peut réliser le CRUD sur tous les élements sauf les Responsables, les Coachs, les Sportifs, les Fiches de paie. Mais il peut consulter ses fiches de paies sans les modifier.
- [ ] Un sportif ne peut pas se connecter au backoffice et donc effectuer des actions de CRUD sur backoffice.
- [ ] Un sportif peut se connecter sur le front et réaliser des réservations.
- [ ] Un sportif peut se connecter sur le front et consulter son bilan.
- [ ] Un sportif peut se connecter sur le front et annuler une réservation.
- [ ] Un sportif peut se connecter sur le front et consulter le planning des séances.

## Front Angular

- [ ] Uniquement les sportif peuvent se connecter
- [ ] Bilan pour un sportif
- [ ] Un sportif peut visualiser les informations de son profil
- [ ] Un internaute et les sportifs peuvent voir les coachs, mais unqiuement les sportifs peuvent voir le détail d'un coach
- [ ] Les séances, le planning proposées peuvent unqiuement être visualiser par un sportif
- [ ] Les reservations peuvent uniquement être visualisé par le sportif
- [ ] Responsive mobile
